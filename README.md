## Overview

A quick introduction to tmux, a terminal multiplexer for managing persistent sessions on HPC clusters.

## Building Locally

**Using pip:**
```bash
pip install -r requirements.txt
mkdocs serve
```

**Using pixi (recommended):**
```bash
pixi run serve
```

Visit http://127.0.0.1:8000
